# Provider icons

Enlarged provider badges over the JetBrains mark. `provider-icon.tsx` renders the full-color desktop artwork using the paths and colors in `artwork.ts`; these SVGs supply adaptive monochrome fallback masks. Badge geometry occupies 18.5 of the 32 viewBox units, with a 14.5-unit provider mark.

- JetBrains geometry: [Simple Icons JetBrains SVG](https://github.com/simple-icons/simple-icons/blob/develop/icons/jetbrains.svg). Brand reference: [JetBrains brand assets](https://www.jetbrains.com/company/brand/).
- OpenAI, Claude and Pi badge geometry: corresponding SVG assets shipped with the installed BB provider plugins.
- No fonts, scripts or external image resources are required.
