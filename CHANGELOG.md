# Changelog

## 0.1.2 — 2026-11-03

- Fixed vertical alignment of Central credits when they are the only item in the thread context banner.
- Added the **Show credits in banner** setting (`showCreditsInBanner`), enabled by default. Changes apply immediately and affect only the banner; context card and Provider usage credits remain available.
- Added tests for banner visibility with the setting enabled and disabled, including preservation of context card credits.
